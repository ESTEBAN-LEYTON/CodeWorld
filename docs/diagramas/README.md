# Diagramas de CodeWorld

Imágenes PNG de 1920×1080 para el video y el informe. Muestran el código real al 5 de noviembre de 2026. Para cambiarlos, edita `fuente/generar_diagramas.py` y ejecuta `npm run diagramas` desde la raíz del repositorio.

| Imagen | Qué explicar |
| --- | --- |
| `01-mapa-general` | Las tres capas y por qué el programa del alumno se evalúa en su navegador |
| `02-del-bloque-al-robot` | Qué ocurre al presionar «Ejecutar»: bloques, lista de instrucciones, resultado y animación |
| `03-interpretador` | Cómo recorre las instrucciones, el límite de 200 pasos y los cinco finales posibles |
| `04-guias-correctivas` | Cómo cada error se convierte en una pista sin dar la solución |
| `05-progreso-sin-conexion` | Cómo se guarda el avance y se sincroniza al volver internet, sin duplicar XP |
| `06-login-tutor-2fa` | El doble factor del tutor, paso a paso |
| `07-registro-alumno` | Datos mínimos, consentimiento y Ley 19.628 |
| `08-modelo-de-datos` | Las siete tablas y sus relaciones |
| `09-apertura-sin-internet` | El service worker y lo que se conserva en el dispositivo |
| `10-peticion-api` | Los filtros de seguridad por los que pasa cada petición |
| `11-estado-del-software` | Qué está probado, qué falta verificar y qué está pendiente |
